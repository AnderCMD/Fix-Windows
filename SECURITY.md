# Security Policy

## Supported Versions

This project is a single-script tool without formal version releases. The
latest version on the `main` branch is the only one that receives security
attention.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue in this project (for example, a way the
script could be used to run unintended or malicious commands), please report
it privately rather than opening a public issue.

You can report a vulnerability by:

- Opening a [GitHub Security Advisory](https://github.com/AnderCMD/Fix-Windows/security/advisories/new) for this repository, or
- Contacting the maintainer directly via their [GitHub profile](https://github.com/AnderCMD).

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or proof-of-concept code.

We will acknowledge your report as soon as possible and work with you to
understand and address the issue.
